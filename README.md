# Amnezia Router Update

Универсальный установщик-обновлятор пакетов AmneziaWG для поддерживаемых сборок OpenWrt. Текущая версия: **1.0.2**.

## Что делает

- определяет версию OpenWrt, target/subtarget, модель, ядро и пакетный менеджер;
- создаёт резервную копию `/etc/config`, источников пакетов и списка установленных пакетов;
- использует установщик проекта [2Grey/awg-openwrt](https://github.com/2Grey/awg-openwrt), который подбирает пакеты под версию OpenWrt и платформу;
- обновляет пакеты AWG и русскую локализацию;
- не создаёт и не меняет VPN-интерфейсы и не перезагружает роутер автоматически;
- прекращает работу для версий OpenWrt вне заявленного диапазона `24.10.0–24.10.8` и `25.12.0–25.12.5`.

**Важно:** скрипт не поддерживает буквально любой роутер/прошивку. Если для точной сборки нет подходящих пакетов или совместимого модуля ядра, установщик должен завершиться ошибкой. Не используйте `--force` для установки несовместимого `kmod`.

## Запуск

Запускайте от `root` по SSH. Подтверждение не запрашивается: после проверок и создания резервной копии скрипт сразу запускает установщик AWG.

```sh
wget -O /tmp/amnezia_router_update.sh https://raw.githubusercontent.com/TMN88/amnezia_router_update/main/amnezia_router_update.sh && sh /tmp/amnezia_router_update.sh
```

## После обновления

1. Запланируйте перезагрузку роутера, чтобы загрузить обновлённый модуль ядра.
2. После перезагрузки проверьте VPN-интерфейс, трафик и DNS.
3. При устаревшем интерфейсе LuCI обновите страницу с `Ctrl+F5`.

Резервная копия сохраняется в `/root/amnezia_router_update-backup-YYYYMMDD-HHMMSS/`.

## Ограничения

- Для пакетов ядра требуется точное соответствие версии/ABI ядра.
- Нет гарантий для OpenWrt Snapshot, vendor firmware и версий вне указанного диапазона.
- Скрипт не тестирует реальный туннель и не доказывает совместимость конкретной серверной конфигурации.
- Перед применением на основном роутере тестируйте на запасном устройстве.

## Проверки

Проверку синтаксиса Shell (`sh -n`), справки (`-h`) и имитационный тест можно запускать локально. Это не заменяет проверку обновления пакетов на физическом роутере.
